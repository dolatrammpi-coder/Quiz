What are Antonyms?

Antonyms are words which have opposite meaning - opposite word. Example: Big x Small, Happy x Sad, Fast x Slow, Good x Bad, Easy x Difficult, Rich x Poor, Strong x Weak, Brave x Coward, Honest x Dishonest, Day x Night, Hot x Cold, Light x Dark, Love x Hate, Begin x End, Buy x Sell, Come x Go. For SSC CGL, CHSL, CPO, Railway, Banking, CTET antonyms are very important because direct antonym questions asked - Choose antonym of Abandon, Honest, Brave, Diligent, Abundant. One word given, four options given, you have to choose opposite meaning word. Antonym is exact opposite - not similar but opposite. Example: Honest opposite is Dishonest, Brave opposite is Coward, Diligent opposite is Lazy, Abundant opposite is Scarce. Antonyms help to understand vocabulary better - if you know word and its opposite, you remember better. In sentence: He is honest, He is not dishonest - opposite words honest dishonest. Antonyms are used to show contrast - He is rich but his brother is poor - rich x poor contrast.

Important Rule: Prefix-Based Antonyms - Many antonyms made by adding prefix un, in, im, dis, mis, non, il, ir. Example: Honest x Dishonest (add dis), Happy x Unhappy (add un), Possible x Impossible (add im), Regular x Irregular (add ir), Legal x Illegal (add il), Accurate x Inaccurate (add in), Manage x Mismanage (add mis), Sense x Nonsense (add non). Exam trick: If you don't know antonym, try adding prefix un/in/im/dis - often correct opposite. Example: Antonym of Happy? Unhappy (un+). Antonym of Possible? Impossible (im+). Antonym of Honest? Dishonest (dis+). Antonym of Regular? Irregular (ir+). But not always - Brave x Coward not prefix, Big x Small not prefix, Good x Bad not prefix - these are different words opposite, not prefix. So two types: prefix antonyms (same root with prefix) and different word antonyms (completely different word).

Types of Antonyms

Common Antonyms, Exam-Oriented Antonyms, Contextual Antonyms

Common Antonyms: Daily life easy opposite words - Big x Small, Happy x Sad, Fast x Slow, Good x Bad, Easy x Difficult, Rich x Poor, Strong x Weak, Hot x Cold, Day x Night, Light x Dark, Love x Hate, Come x Go, Buy x Sell, Begin x End, Open x Close, High x Low, Up x Down, In x Out, Left x Right. These are easy common antonyms asked in basic exams CTET, Railway. Exam-Oriented Antonyms: SSC CGL CHSL high level vocabulary antonyms - Abandon x Keep, Abundant x Scarce, Brave x Coward, Benevolent x Cruel, Candid x Secretive, Cordial x Hostile, Diligent x Lazy, Ephemeral x Permanent, Frank x Secretive, Generous x Selfish, Honest x Dishonest, Humble x Arrogant, Industrious x Lazy, Meticulous x Careless, Modest x Arrogant, Punctual x Late, Wealthy x Poor, Ample x Scarce. These are tough formal words opposite for SSC high level. Contextual Antonyms: Antonym depends on context sentence - word may have different opposite in different context. Example: Light has two meanings - Light (not heavy) antonym Heavy (Light bag x Heavy bag), Light (bright) antonym Dark (Light colour x Dark colour). So same word Light has two antonyms based on context Heavy or Dark. Hard has two meanings - Hard (difficult) antonym Easy (Hard work x Easy work), Hard (solid) antonym Soft (Hard stone x Soft stone). So always check context sentence for contextual antonym.

Antonyms of Verbs, Nouns, Adjectives, Adverbs, Prefix-Based, Frequently Asked

Antonyms of Verbs: Verb opposite action words - Buy x Sell, Go x Come, Begin x End, Give x Take, Come x Go, Arrive x Depart, Create x Destroy, Make x Break, Love x Hate, Help x Hinder, Allow x Forbid, Increase x Decrease, Rise x Fall, Build x Demolish, Teach x Learn, Buy-Purchase? Actually Buy x Sell opposite verb. Example: He will buy car antonym He will sell car opposite action buy x sell verbs antonyms. Antonyms of Nouns: Noun opposite name words - Success x Failure, Victory x Defeat, Love x Hate, Courage x Cowardice, Honesty x Dishonesty, Arrival x Departure, Creation x Destruction, Teacher x Student, Day x Night, Life x Death, Joy x Sorrow, Peace x War, Friend x Enemy. Example: Success x Failure both nouns opposite. Antonyms of Adjectives: Adjective opposite quality words - Happy x Sad, Big x Small, Fast x Slow, Good x Bad, Easy x Difficult, Rich x Poor, Strong x Weak, Brave x Coward, Honest x Dishonest, Beautiful x Ugly, Tall x Short, Fat x Thin, Old x New, Modern x Ancient, Generous x Selfish. Adjective describes noun quality opposite quality words antonyms. Antonyms of Adverbs: Adverb opposite how action done - Quickly x Slowly, Happily x Sadly, Easily x Difficultly, Loudly x Softly, Truly x Falsely, Carefully x Carelessly, Bravely x Cowardly, Honestly x Dishonestly. Adverb describes verb how action done opposite manner antonyms adverb opposite manner. Prefix-Based Antonyms: Using prefix un, in, im, dis, mis, non, il, ir to make opposite - Happy x Unhappy (un), Possible x Impossible (im), Honest x Dishonest (dis), Regular x Irregular (ir), Legal x Illegal (il), Accurate x Inaccurate (in), Manage x Mismanage (mis), Sense x Nonsense (non). Frequently Asked Antonyms: SSC most asked repeated antonyms - Abandon x Keep/Stay, Abundant x Scarce/Meager, Brave x Coward/Timid, Benevolent x Cruel/Malevolent, Candid x Secretive/Biased, Cordial x Hostile/Cold, Diligent x Lazy/Idle, Ephemeral x Permanent/Eternal, Frank x Secretive/Reserved, Generous x Selfish/Stingy, Honest x Dishonest/Corrupt, Humble x Arrogant/Proud, Industrious x Lazy, Meticulous x Careless/Sloppy, Modest x Arrogant/Boastful, Punctual x Late/Tardy, Wealthy x Poor/Needy.

Tips for Antonym Questions in SSC

Most important SSC tricks: 1) Learn 500 most frequent SSC antonyms list by heart - Abandon-Keep, Abundant-Scarce, Brave-Coward, Diligent-Lazy, Honest-Dishonest, Generous-Selfish, etc. 2) Context matters - if sentence given, read sentence meaning then choose antonym according to sentence context, not just word alone. Example: Light in weight context antonym Heavy, Light in brightness context antonym Dark. 3) Part of speech same - Antonym must be same part of speech - Noun antonym noun, Verb antonym verb, Adjective antonym adjective. Example: Honest is adjective, Dishonest is adjective same part adjective adjective, not Dishonesty is noun wrong part. 4) Prefix trick - Try adding un/in/im/dis/il/ir/mis/non prefix to make opposite - often correct if you don't know different word opposite. Example: Antonym of Happy? Unhappy (un). Antonym of Possible? Impossible (im). 5) Elimination - If you don't know meaning, eliminate synonym options (same meaning) - antonym is opposite meaning, not same. 6) Root words - Learn Latin Greek roots - Bene=Good Benevolent opposite Malevolent Bad, Phil=Love Philanthropist opposite Misanthropist hate.

Exam Tip: SSC most asked antonyms repeat every year - Learn these 20 by heart: Abandon-Keep/Forsake x Keep, Abundant-Scarce/Meager, Brave-Coward/Timid, Benevolent-Cruel/Malevolent, Candid-Secretive/Biased, Cordial-Hostile/Cold, Diligent-Lazy/Idle, Ephemeral-Permanent/Eternal, Frank-Secretive/Reserved, Generous-Selfish/Stingy, Honest-Dishonest/Corrupt, Humble-Arrogant/Proud, Industrious-Lazy, Meticulous-Careless/Sloppy, Modest-Arrogant/Boastful, Punctual-Late/Tardy, Wealthy-Poor/Needy, Diligent-Lazy, Ample-Scarce, Enormous-Tiny. For contextual antonyms, always read full sentence - antonym must fit sentence meaning opposite, not just word meaning alone. Prefix trick: un, in, im, dis, il, ir, mis, non make opposite quickly.
