One-Liner Questions

What is the fundamental definition of Computer Hardware?
All the physical and tangible components of a computer that can be touched and seen are called hardware.

What is the primary relationship between hardware and software?
Hardware provides the physical structure, whereas software provides the instructions that operate the hardware.

What are the four main functional units of a computer system?
Input Unit, Processing Unit (CPU), Output Unit, and Storage Unit (Memory).

What is 'Firmware'?
Software/instructions stored in a hardware device's permanent ROM or non-volatile flash memory that are essential for booting and basic control of the device.

What is the main concept of the Von Neumann Architecture?
According to this model, both data and instructions are stored in the same shared memory space (Stored-program concept).

What is the function of a 'Bus' in computer architecture?
An electronic communication path that transfers data, signals, and addresses between different components of a computer.

What is the characteristic of a 'Data Bus'?
It is a bidirectional bus that carries actual data between the CPU, memory, and input/output devices.

What is the nature of an 'Address Bus'?
It is a unidirectional bus that carries the address of the memory location specified by the CPU.

Which capacity of a computer is determined by the Address Bus Width?
It determines the maximum RAM capacity (Addressable Memory) that the computer can directly access.

What is the main purpose of a 'Control Bus'?
Sending control and timing signals to synchronize operations across various components.

Which three buses combine to form the 'System Bus'?
Data Bus, Address Bus, and Control Bus.

What is meant by 'Peripheral Devices'?
External devices connected to a computer from the outside to expand its functionality (input, output, storage), such as a mouse or printer.

What does 'Plug and Play' (PnP) technology mean?
Devices that the operating system automatically detects and enables as soon as they are connected to the computer, without requiring manual configuration.
Tap to view answer
What is the difference between a Serial Port and a Parallel Port?
A serial port transmits 1 bit of data at a time, whereas a parallel port transmits multiple bits (typically 8 bits) simultaneously.
Tap to view answer
What is the full form of USB, and what is its main advantage?
Universal Serial Bus; it is a universal standard interface that provides high-speed data transfer and power delivery.

It is a reversible connector that supports high-speed data, 4K video, and fast charging (Power Delivery).

One-Liner Questions

What is the main function of an Output Device?
Converting binary data processed by the computer into a human-understandable form (visual, audio, or printed).
Tap to view answer
What is the difference between Soft Copy and Hard Copy output?
Soft copy is temporary in digital form on a screen/audio, whereas hard copy is a permanent physical form printed on paper.
Tap to view answer
What was used to form images in a CRT monitor?
An electron gun firing an electron beam onto a phosphor-coated screen.
Tap to view answer
What is the full form of LCD, and what technology is it based on?
Liquid Crystal Display; it creates images by blocking or passing light through liquid crystals.
Tap to view answer
What is the main technical difference between LCD and LED monitors?
LCD uses CCFL fluorescent lamps for backlighting, whereas LED uses Light Emitting Diodes (LEDs).
Tap to view answer
What is the key feature of an OLED (Organic Light Emitting Diode) display?
Its pixels emit their own light (self-emissive), delivering true black and high contrast without needing a backlight.
Tap to view answer
What does Monitor Resolution mean?
The total number of pixels arranged horizontally and vertically on a screen (e.g., 1920x1080).
Tap to view answer
What is a 'Pixel'?
Picture Element; the smallest minimum unit of an image on a digital display screen.
Tap to view answer
What is meant by Aspect Ratio?
The proportional relationship between a screen's width and height (such as 16:9 or 4:3).
Tap to view answer
What does a monitor's 'Refresh Rate' measure, and what is its unit?
How many times per second the screen updates with a new image; it is measured in Hertz (Hz).
Tap to view answer
What is 'Response Time' in the context of a display?
The time taken by a pixel to change from one color to another (e.g., black to white), measured in milliseconds (ms).
Tap to view answer
What is 'Dot Pitch' (Pixel Pitch)?
The distance (in millimeters) between two adjacent phosphor dots/pixels of the same color; the smaller it is, the sharper the image.
Tap to view answer
On what principle do Impact Printers operate?
They print characters by physically striking an inked ribbon against paper (mechanical impact).
Tap to view answer
What is the characteristic of Non-Impact Printers?
They print quietly without any physical impact on paper, using chemicals, heat, laser, or ink spray.
Tap to view answer
What type of printer is a Dot Matrix Printer?
It is an impact character printer that prints dot by dot using a matrix of pins.
Tap to view answer
In which unit is the speed of a Dot Matrix Printer measured?
CPS (Characters Per Second).
Tap to view answer
Which category does a Daisy Wheel Printer belong to?
It is an impact printer that prints by striking characters embossed on the petals of a circular wheel.
Tap to view answer
What is used in the printing process of a Laser Printer?
A laser beam, a photosensitive drum, and dry powdered toner.
Tap to view answer
What are the units for speed and print quality of a Laser Printer?
Speed is measured in PPM (Pages Per Minute) and quality is measured in DPI (Dots Per Inch).
Tap to view answer
How does an Inkjet Printer print?
It prints by spraying microscopic droplets of liquid ink onto paper.
Tap to view answer
How does a Thermal Printer work, and where is it used?
It prints using heat on heat-sensitive paper; it is used in ATM receipts and POS billing machines.

What is the main difference between a Plotter and a Printer?
A plotter draws continuous vector lines using pens to create large maps, banners, and CAD diagrams.
