One-Liner Questions

What is the fundamental definition of Data?
Data is a collection of unprocessed raw facts, figures, characters, or symbols that carry no meaning or context on their own.

What is the difference between Information and Data?
When data is processed, organized, and made meaningful within a specific context, it is called Information.

What is Knowledge in the context of Computer Science?
An organized collection of information used for decision-making, problem-solving, or drawing conclusions is called Knowledge.

What is the exact definition of a Database?
A database is an organized, digital collection of logically related data that can be easily accessed, managed, and updated.

What was the Traditional File Processing System?
The conventional, uncoordinated system prior to the advent of DBMS where data was stored separately across various computer files (such as text or binary files).
Tap to view answer
What does Data Redundancy mean in a traditional file system?
The unnecessary repetition or duplication of the same data across multiple files is called Data Redundancy.
Tap to view answer
What is Data Inconsistency?
When data is duplicated and changes made in one place are not updated in other places, resulting in differing values for the same data; this is called Data Inconsistency.
Tap to view answer
What were the main limitations of the traditional file system?
Data redundancy, data inconsistency, program-data dependence, limited data sharing, and weak security mechanisms were its major limitations.
Tap to view answer
What is meant by Program-Data Dependence?
In a file system, any change to the physical format of a file requires modifying the code of all application programs linked to it.
Tap to view answer
What is the primary objective of the database approach?
To minimize data redundancy and maintain data consistency and integrity.
Tap to view answer
What does Data Integrity mean?
Maintaining the accuracy, authenticity, and validity of the data stored in a database.
Tap to view answer
What is meant by Concurrent Access in a database?
The ability of multiple users to safely access and use a database at the exact same time.
Tap to view answer
Why did the problem of Data Isolation arise in file systems?
Because data was scattered across different files and formats, making it difficult to retrieve related information together.
Tap to view answer
What does the term Atomicity mean in database management?
That a transaction either succeeds completely or is not applied at all ('All or Nothing').
Tap to view answer
What is the technical definition of Metadata?
'Data about Data' — i.e., data that describes the structure, data types, rules, and constraints of a database.
Tap to view answer
What is the function of a Data Dictionary or System Catalog?
A central repository in a database that stores metadata, table definitions, user privileges, and relationships.
Tap to view answer
How is 'Centralized Control' a major advantage of a database?
Having all data in one place or under a controlled system makes security, backup, and enforcement of standards much easier.
Tap to view answer
How is Data Security implemented in a database?
Through user authentication, Role-Based Access Control (RBAC), and data encryption.
Tap to view answer
What are the main challenges or drawbacks of adopting a database?
High cost of the DBMS, complexity, high hardware requirements, and the risk of a single point of failure (Central Failure).
Tap to view answer
Why is Persistence considered a property of a database?
Because data stored in a database remains safe in non-volatile storage even after the system is shut down or loses power.
Tap to view answer
How is Data Sharing made possible in the database approach?
By providing different departments and applications access to the same up-to-date data from a central database.
Tap to view answer
What does Enforcement of Standards signify in a DBMS?
Applying uniform data formats, naming conventions, and entry rules across the organization.

What is an example of Unstructured Data in databases?
Audio, video, social media posts, and image files that have no predefined tabular structure.

What is the hallmark of Structured Data?
Data stored in a fixed format of rows and columns (such as SQL tables).
Tap to view answer
Which is an example of Semi-structured Data?
XML and JSON files, which contain tags or markup but lack the rigid structure of traditional database tables.

What is the correct ascending order of the Data Hierarchy?
Bit -> Byte/Character -> Field -> Record -> File/Table -> Database.

What is the smallest unit in the computer data hierarchy?
Bit (Binary Digit: 0 or 1).

What does a Character or Byte represent?
A group of 8 bits representing a letter, digit, or special symbol.

What is the definition of a Field or Attribute?
A group of one or more characters representing a specific property or characteristic of an entity (e.g., Name, Age, Roll Number).

A group of related fields providing complete information about a specific object or person (a single row of a table).

What does Data Independence mean?
