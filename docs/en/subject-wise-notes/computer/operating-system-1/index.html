One-Liner Questions

What is the basic definition of an Operating System (OS)?
It is a core collection of system software that acts as an interface between computer hardware and the user.

What is the primary objective of an Operating System?
To manage computer resources (CPU, memory, I/O devices) efficiently and provide a convenient environment for users to run programs.
Tap to view answer
What part of an Operating System is the Kernel?
It is the most central and critical component of the OS that communicates directly with the hardware.
Tap to view answer
What is meant by the Booting process?
The process of powering on a computer and loading the operating system into main memory (RAM).
Tap to view answer
Give an example of a Single-User Operating System.
MS-DOS, in which only one user can work at a time.
Tap to view answer
What is the main feature of a Multi-User Operating System?
It allows multiple users to share computer resources simultaneously over a network.
Tap to view answer
How does a Batch Operating System work?
It collects similar jobs into batches and executes them sequentially without user intervention.
Tap to view answer
What is the main purpose of a Multitasking or Time-Sharing Operating System?
To keep multiple tasks active by rapidly dividing CPU time among different jobs and users.
Tap to view answer
Where is a Real-Time Operating System (RTOS) used?
In systems where strict timing and instant response are critical, such as spacecraft, missile control, and medical equipment.
Tap to view answer
What is the difference between a Hard Real-Time and a Soft Real-Time system?
In a Hard RTOS, missing a deadline results in complete failure, whereas in a Soft RTOS, minor delays may be acceptable.
Tap to view answer
What is the key characteristic of a Distributed Operating System?
It enables a group of independent computers to function together as a single integrated system.

What is a Process?
A computer program currently in execution.
Tap to view answer
What is stored in a Process Control Block (PCB)?
All information related to a process, including its state, program counter, CPU registers, and memory allocation.
Tap to view answer
What are the main states of a process?
New, Ready, Running, Waiting (Blocked), and Terminated (Completed).
Tap to view answer
What is Context Switching?
The process by which the CPU pauses one process, saves its state, and loads the state of another process.
Tap to view answer
What is the primary goal of CPU Scheduling?
To maximize CPU utilization and minimize waiting time to improve overall system efficiency.
Tap to view answer
What is the difference between Preemptive and Non-Preemptive scheduling?
In preemptive scheduling, a running process can be forcibly interrupted, whereas in non-preemptive scheduling, it runs until completion or blocking.
Tap to view answer
What is the full form of FCFS in scheduling algorithms?
First-Come, First-Served; the process that arrives first gets the CPU first.
Tap to view answer
What is the key feature of SJF (Shortest Job First) scheduling?
The process with the shortest CPU burst time is executed first.
Tap to view answer
What is Round Robin scheduling based on?
It is a preemptive scheduling algorithm based on a fixed time slice called a Time Quantum.
Tap to view answer
What is a Thread also known as?
A 'Lightweight Process,' representing the smallest executable unit within a process.
Tap to view answer
When does a Deadlock occur?
When two or more processes wait indefinitely for resources held by each other.
Tap to view answer
What are Coffman's conditions for a Deadlock to occur?
Mutual Exclusion, Hold and Wait, No Preemption, and Circular Wait.

What is the main function of Memory Management?

What is the difference between a Logical Address and a Physical Address?
A logical address is generated by the CPU, whereas a physical address refers to the actual location in the memory unit.

What is the process of mapping a logical address to a physical address called?

Tap to view answer
What is Swapping?
Temporarily moving a process from main memory to secondary disk storage (backing store) and bringing it back when needed.

What is the main advantage of Virtual Memory?

How is memory divided in Paging?

When does a Page Fault occur?
When a requested page is not present in main memory and must be fetched from the disk.

What is Thrashing?
A condition where the OS spends most of its time swapping pages instead of executing useful work, severely slowing down the system.
