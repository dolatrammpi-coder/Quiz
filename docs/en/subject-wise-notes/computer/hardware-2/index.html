Central Processing Unit, Registers, Cache Memory, and Motherboard (Hardware 2)

Computer Memory and Storage Media

🔍

One-Liner Questions

What is the basic definition of Computer Memory?
Computer memory is a collection of electronic components that temporarily or permanently stores data, instructions, and processing results.
Tap to view answer
Why is the computer's Main Memory called Primary Memory?
Because it is directly accessible by the CPU and holds the executable code and data required for system operation.
Tap to view answer
What is the main objective of Memory Hierarchy?
To achieve maximum processing performance at minimum cost by balancing cost, storage capacity, and access speed.
Tap to view answer
What is the fundamental difference between Volatile and Non-Volatile memory?
Volatile memory loses its data when power is turned off (e.g., RAM), whereas non-volatile memory retains data even when power is off (e.g., ROM and HDD).
Tap to view answer
Why is Random Access Memory (RAM) called 'Random Access'?
Because data at any memory location (address) can be accessed in equal time, independent of its physical position.
Tap to view answer
What is the structural characteristic of Static RAM (SRAM)?
SRAM uses flip-flops or transistor circuits to store data, so it does not require frequent refreshing.
Tap to view answer
Why does Dynamic RAM (DRAM) need to be continuously refreshed?
DRAM stores data as electrical charge in capacitors, which gradually discharge over time.
Tap to view answer
How do SRAM and DRAM compare in terms of speed and cost?
SRAM is extremely fast and expensive, whereas DRAM is comparatively slower, cheaper, and offers higher density.
Tap to view answer
On what principle does SDRAM (Synchronous DRAM) operate?
It transfers data synchronously with the computer's system clock.
Tap to view answer
What is the key feature of DDR (Double Data Rate) SDRAM?
It transfers data twice per clock cycle, on both the rising and falling edges of the clock signal.
Tap to view answer
Which technological advancements have driven the evolution from DDR1 to DDR5?
Reduced voltage levels (power savings), increased bus width, and major improvements in clock frequency and bandwidth.
Tap to view answer
What is the primary function of Read Only Memory (ROM)?
To permanently store the firmware or BIOS/UEFI instructions required to boot the computer.
Tap to view answer
What is Mask ROM (MROM)?
A type of ROM whose data is hard-wired and pre-programmed during the manufacturing process and cannot be altered.
Tap to view answer
What is the limitation of PROM (Programmable ROM)?
PROM can be programmed only once using a special device (PROM Burner), after which it cannot be erased (OTP - One-Time Programmable).
Tap to view answer
What is used to erase data in EPROM (Erasable Programmable ROM)?
Ultraviolet (UV) rays are directed through a quartz window on the EPROM chip to erase its data.
Tap to view answer
What advantage does EEPROM (Electrically Erasable Programmable ROM) have over EPROM?
EEPROM can be erased and reprogrammed byte-by-byte using electrical signals without removing the chip.
Tap to view answer
What is the difference between Flash Memory and traditional EEPROM?
Flash memory is a type of EEPROM, but it can erase and write data rapidly at the block level rather than byte-by-byte.
Tap to view answer
How does Cache Memory improve CPU performance?
It acts as an ultra-fast buffer between the CPU and main memory, enabling instant access to frequently used instructions.
Tap to view answer
What is the hierarchy of physical location and speed among L1, L2, and L3 cache memory?
L1 cache is the fastest and located inside the CPU core; L2 is located near the core; and L3 cache is the largest (often shared) but slightly slower than L1/L2.
Tap to view answer
What are CPU Registers?
They are the fastest and smallest temporary storage units located inside the processor, holding data and addresses during execution.
Tap to view answer
What is the function of the Accumulator (AC) register?
It temporarily stores intermediate results of arithmetic and logical operations performed by the ALU.
Tap to view answer
What is the role of the Program Counter (PC) register?
It tracks and holds the memory address of the next instruction to be executed.
Tap to view answer
What data does the Instruction Register (IR) hold?
It holds the current instruction being decoded and executed.
Tap to view answer
What is the difference between Memory Address Register (MAR) and Memory Buffer Register (MBR/MDR)?
MAR holds the address of the location to be read from or written to, whereas MBR holds the actual data or instruction.
Tap to view answer
What is the importance of a Buffer in memory management?
A buffer provides a temporary memory area to balance differences in data transfer rates between devices of varying speeds (such as CPU and printer).

One-Liner Questions

What is the primary function of Secondary Storage?
To store data, operating systems, software programs, and files permanently and on a large scale (mass storage).
Tap to view answer
On what magnetic principle does a Hard Disk Drive (HDD) operate?
It records data as magnetic polarity on spinning disk platters coated with magnetic material using a read/write head.
Tap to view answer
What are 'Tracks' and 'Sectors' in a hard disk?
Concentric circles on a platter's surface are called 'tracks', and each divided small segment of a track is called a 'sector' (typically 512 bytes or 4 KB).
Tap to view answer
What does 'Cylinder' mean in the context of a hard disk?
The vertical group of all tracks located at the same radius across all platters is called a cylinder.
Tap to view answer
What is the definition of Seek Time?
The time taken by the read/write head to reach the target track is called seek time.
Tap to view answer
What does Rotational Latency represent?
The time taken for the desired sector to rotate under the read/write head is called rotational latency.
Tap to view answer
What is the mathematical formula for Access Time?
Access Time = Seek Time + Rotational Latency + Transfer Time.
Tap to view answer
How does RPM (Revolutions Per Minute) affect hard disk speed?
Higher RPM (such as 5400, 7200, or 10000 RPM) reduces rotational latency and increases data transfer speed.
Tap to view answer
Why is a Solid State Drive (SSD) much faster than a traditional HDD?
Because an SSD has no mechanical or moving parts; it operates on semiconductor NAND flash memory.
Tap to view answer
What is the difference between the main types of NAND flash memory (SLC, MLC, TLC, QLC)?
The number of bits per cell increases (SLC=1, MLC=2, TLC=3, QLC=4), which increases storage density but reduces endurance and speed.
Tap to view answer
What is the key feature of the NVMe (Non-Volatile Memory Express) protocol?
It uses the high-speed PCIe bus to reduce SSD latency and provide parallel data processing capability.
Tap to view answer
What is the function of the TRIM command in an SSD?
It allows the operating system to mark data blocks that are no longer in use, helping maintain garbage collection and write speeds.
Tap to view answer
Which technology does an Optical Disk use to read and write data?
It uses a laser beam and light reflection to read pits and lands.
Tap to view answer
What do 'Pits' and 'Lands' mean on an optical disk surface?
Pits are microscopic concave depressions and lands are flat surfaces, which represent binary '0' and '1' through differences in laser reflection.
Tap to view answer
What is the standard storage capacity of a Compact Disc (CD)?
A standard CD typically has a capacity of 700 MB (or about 80 minutes of audio).
Tap to view answer
What is the fundamental difference between CD-R and CD-RW?
Data can be written only once on a CD-R (WORM), whereas data on a CD-RW can be erased and rewritten multiple times.
Tap to view answer
Why is the storage capacity of a Digital Versatile Disc (DVD) greater than that of a CD?
DVDs use a shorter-wavelength laser and smaller pits, giving a single-layer DVD a capacity of 4.7 GB.
Tap to view answer
What is the maximum capacity of a double-layer, dual-sided DVD?
A Dual-Layer Dual-Sided DVD can have a storage capacity of up to 17 GB.
Tap to view answer
Which type of laser beam is used in a Blu-ray Disc (BD)?
It uses a 405 nm wavelength blue-violet laser, which has an extremely fine beam.
Tap to view answer
What are the storage capacities of single-layer and double-layer Blu-ray Discs?
A single-layer disc has a capacity of 25 GB, and a double-layer disc has a capacity of 50 GB.
Tap to view answer
How high can the capacity of a BDXL (Blu-ray Disc Extra Large) disc reach?
Multi-layer BDXL discs have a storage capacity ranging from 100 GB to 128 GB.
Tap to view answer
What is the maximum capacity of Ultra HD Blu-ray?
It uses triple-layer formats with capacities of 66 GB and 100 GB for 4K UHD video.
Tap to view answer
What is meant by WORM (Write Once, Read Many) media?
Storage media on which data can be written only once but read repeatedly without modification (e.g., CD-R, DVD-R).
Tap to view answer
What does the 'X' factor represent in optical disc drive data transfer speeds?
'X' is a multiplier of the base data transfer rate (e.g., for CD 1X = 150 KB/s, for DVD 1X = 1.385 MB/s).
Tap to view answer
What is the durability difference between an HDD and an SSD?
Because an SSD has no moving parts, it is shock-resistant and consumes less power.
