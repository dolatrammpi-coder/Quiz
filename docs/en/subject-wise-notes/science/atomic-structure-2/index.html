Key Facts & Contributions
Atomic Structure 2
Particle/Shell/ConceptElectronic Configuration or CharacteristicValency/Example
K Shell (n = 1)Maximum capacity of 2 electrons per the 2n² rule1s² (Helium: 2)
L Shell (n = 2)Maximum capacity of 8 electrons per the 2n² rule2s² 2p⁶ (Neon: 2, 8)
M Shell (n = 3)Maximum capacity of 18 electrons per the 2n² rule3s² 3p⁶ 3d¹⁰ (Argon: 2, 8, 8)
N Shell (n = 4)Maximum capacity of 32 electrons per the 2n² rule4s² 4p⁶ 4d¹⁰ 4f¹⁴ (Krypton)
IsotopesSame atomic number (Z) but different mass number (A)Isotopes of hydrogen (1H¹, 1H², 1H³)
IsobarsSame mass number (A) but different atomic number (Z)18Ar⁴⁰, 19K⁴⁰, 20Ca⁴⁰
IsotonesDifferent elements with the same number of neutrons (A - Z) in the nucleus6C¹⁴, 7N¹⁵, 8O¹⁶ (Neutrons = 8)
IsoelectronicDifferent ions or atoms having the same total number of electronsNa⁺, Mg²⁺, Al³⁺, F⁻, Ne (Total electrons = 10)
