What is Sentence Rearrangement?

Sentence Rearrangement also called Para Jumbles is arranging jumbled sentences in correct logical order to make meaningful paragraph. Four or five sentences given random order P Q R S, you have to arrange correct sequence like Q S P R. For SSC CGL, CHSL, CPO, Railway, Banking, CTET para jumbles are very important because they test reading comprehension, logical thinking, grammar linking. Example: P. He was very hungry. Q. He found some bread. R. Ram went to forest. S. He ate it. Correct order R P Q S - Ram went to forest (opening), He was very hungry (pronoun He for Ram), He found some bread, He ate it (closing). Opening sentence introduces topic, middle sentences develop logically, closing concludes. Trick: Find independent sentence which does not start with pronoun, but, so, however, therefore, this, that, they - independent sentence usually opening.

Important Rule: Opening Sentence Identification: Opening sentence is independent, introduces noun first time, not pronoun he/she/it/they/this/that, not starting with but, however, therefore, so, then, also, moreover, firstly, secondly. Closing Sentence Identification: Closing often has finally, therefore, thus, in conclusion, at last, hence. Pronoun Rule: Pronoun comes after noun - If sentence has He, She, It, They, This, That, pronoun sentence cannot be first, noun sentence must come before pronoun sentence. Example: S1 Ram is boy, S2 He is smart - S1 before S2 because He refers to Ram. Linking Words: but shows contrast, so/therefore shows result, however shows contrast, moreover shows addition, then shows sequence - Link must match logic.

Types of Sentence Rearrangement Techniques

Para Jumbles, Opening and Closing, Logical Sequence, Linking Words

Para Jumbles: Jumbled paragraph 4-5 sentences random order P Q R S, find correct order. Technique: Find opening - independent sentence with noun not pronoun. Find mandatory pairs - sentences which must come together. Example: Pair He found bread + He ate it must be together Q before S because found before ate chronological. Pronoun clue: This/That refers to previous sentence idea. Demonstrative this/that cannot be first. Opening Identification: Look for sentence introducing topic, person, place, idea first time. Usually proper noun, not pronoun, not connector. Example: India is great country can be opening, It is great country cannot be opening because It pronoun needs noun before. Closing Identification: Look for concluding words finally, at last, therefore, thus, hence, in conclusion, so, concluding idea summarising. Closing often gives result, conclusion, final action. Logical Sequence: General to specific, cause to effect, problem to solution, introduction to explanation to conclusion. Example: Problem - Pollution is increasing, Cause - Because vehicles, Effect - So health problems, Solution - Therefore we should plant trees. Logical order problem cause effect solution.

Linking Words, Pronoun Clues, Chronological Order, Cause Effect, Context Based

Linking Words and Connectors: and, but, however, therefore, moreover, furthermore, also, then, so, because, since, thus, hence, firstly, secondly, finally, on the other hand. But/however shows contrast - previous sentence opposite idea must come before but sentence. Therefore/so/thus/hence shows result - result sentence after cause sentence. Moreover/furthermore/also shows addition - addition sentence after base sentence same topic. Then/next/after that shows sequence time. Pronoun and Reference Clues: he, she, it, they, him, her, them, this, that, these, those, such, same - pronoun refers to noun earlier. If sentence starts with He, find Ram/Mohan/boy noun sentence before it. This/That refers to idea previous sentence - This problem refers to problem mentioned earlier, so This sentence after problem sentence. Chronological Order: Time sequence - first, then, next, after, before, yesterday, today, tomorrow, morning, evening, dates. Arrange by time order early to late. Example: He woke up, He brushed, He ate breakfast, He went to school - chronological morning sequence. Cause and Effect Sequence: Cause before effect - Because clause cause first, so clause effect after. Example: It rained heavily (cause), So roads were flooded (effect) - cause before effect. Context-Based Arrangement: Understand overall theme - if paragraph about science, all sentences about science, pick opening general science sentence, not specific example first. Keep theme consistent.

Common Tricks for Para Jumbles in SSC

Most important SSC tricks: 1) Find opening - independent noun sentence not pronoun, not connector. 2) Find mandatory pairs - two sentences which must come together - Example: Pair found bread + ate bread Q S pair chronological found before ate. 3) Pronoun reference - He/She/It/They/This/That must have noun/idea before. 4) Article trick - A boy first time, The boy second time - A before The because A introduces first time, The refers to already introduced. Example: A boy came, The boy was hungry - A sentence before The sentence. 5) Connector logic - But needs opposite idea before, So needs cause before. 6) Time and number - First, second, third sequence order. 7) Elimination - Test options given - try Q S P R order in mind does it make meaningful paragraph? Read quickly. 8) Theme - All sentences about same topic, opening general statement not specific detail first.

Exam Tip: Trick for SSC para jumbles: Step 1 - Find opening independent sentence with proper noun or A + noun, not pronoun, not but/however/so. Step 2 - Find closing with finally/therefore/thus. Step 3 - Find mandatory pairs using pronoun - He sentence after Ram sentence, This sentence after idea sentence, The boy after A boy. Step 4 - Use chronological cause-effect - cause before effect, early time before late time. Step 5 - Check options - given 4 orders, test each quickly which gives meaningful flow. Never pick opening with pronoun he/she/it/they/this/that/but/however/therefore. Opening is always independent introducing topic first time.
