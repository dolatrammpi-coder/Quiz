Shortcuts 1

कंप्यूटर और Windows के सामान्य, दैनिक उपयोग, टेक्स्ट संपादन, फाइल प्रबंधन तथा नेविगेशन से संबंधित महत्वपूर्ण कीबोर्ड शॉर्टकट की विस्तृत अध्ययन सामग्री

🔍

One-Liner Questions

कंप्यूटर में किसी चयनित टेक्स्ट या ऑब्जेक्ट की कॉपी बनाने के लिए किस कीबोर्ड शॉर्टकट का उपयोग किया जाता है?
Ctrl + C
उत्तर देखने के लिए टैप करें
कॉपी या कट किए गए टेक्स्ट या आइटम को किसी स्थान पर पेस्ट करने के लिए कौन सी शॉर्टकट की जाती है?
Ctrl + V
उत्तर देखने के लिए टैप करें
किसी चयनित टेक्स्ट, फाइल या फोल्डर को कट (स्थान परिवर्तन के लिए हटाने) हेतु कौन सा शॉर्टकट है?
Ctrl + X
उत्तर देखने के लिए टैप करें
किसी दस्तावेज या विंडो में सभी सामग्री (All Contents) को एक साथ चुनने के लिए क्या दबाया जाता है?
Ctrl + A
उत्तर देखने के लिए टैप करें
किए गए अंतिम कार्य को पूर्ववत (Undo) करने के लिए किस शॉर्टकट का प्रयोग होता है?
Ctrl + Z
उत्तर देखने के लिए टैप करें
पूर्ववत किए गए कार्य को पुनः करने (Redo) के लिए किस शॉर्टकट का उपयोग किया जाता है?
Ctrl + Y
उत्तर देखने के लिए टैप करें
वर्तमान में खुली हुई फाइल या दस्तावेज को सहेजने (Save) के लिए कौन सा शॉर्टकट उपयोग होता है?
Ctrl + S
उत्तर देखने के लिए टैप करें
किसी दस्तावेज को प्रिंट (Print) करने के लिए किस कीबोर्ड संयोजन का उपयोग किया जाता है?
Ctrl + P
उत्तर देखने के लिए टैप करें
किसी सॉफ्टवेयर या एप्लिकेशन में नया दस्तावेज़ या विंडो खोलने के लिए क्या दबाया जाता है?
Ctrl + N
उत्तर देखने के लिए टैप करें
कंप्यूटर में पहले से मौजूद किसी फाइल या दस्तावेज को खोलने (Open) के लिए कौन सा शॉर्टकट है?
Ctrl + O
उत्तर देखने के लिए टैप करें
वर्तमान में सक्रिय विंडो या टैब को बंद (Close) करने के लिए किस शॉर्टकट का प्रयोग होता है?
Ctrl + W
उत्तर देखने के लिए टैप करें
किसी दस्तावेज या वेबपेज में विशिष्ट शब्द या वाक्य खोजने (Find) के लिए क्या दबाया जाता है?
Ctrl + F
उत्तर देखने के लिए टैप करें
किसी शब्द या वाक्य को ढूँढकर उसे दूसरे शब्द से बदलने (Replace) के लिए कौन सा शॉर्टकट है?
Ctrl + H
उत्तर देखने के लिए टैप करें
चयनित टेक्स्ट को बोल्ड (Bold) करने के लिए किस कीबोर्ड शॉर्टकट का उपयोग किया जाता है?
Ctrl + B
उत्तर देखने के लिए टैप करें
चयनित टेक्स्ट को इटैलिक (Italic - तिरछा) करने के लिए क्या दबाया जाता है?
Ctrl + I
उत्तर देखने के लिए टैप करें
चयनित टेक्स्ट के नीचे रेखा खींचने (Underline) के लिए कौन सा शॉर्टकट प्रयुक्त होता है?
Ctrl + U
उत्तर देखने के लिए टैप करें
Windows ऑपरेटिंग सिस्टम में Start Menu को खोलने या बंद करने के लिए किस कुंजी का उपयोग होता है?
Windows Key
उत्तर देखने के लिए टैप करें
सभी खुली हुई खिड़कियों को छिपाकर सीधे डेस्कटॉप पर जाने के लिए कौन सा शॉर्टकट है?
Windows Key + D
उत्तर देखने के लिए टैप करें
Windows Explorer (फाइल मैनेजर) को सीधे खोलने के लिए किस शॉर्टकट का प्रयोग किया जाता है?
Windows Key + E
उत्तर देखने के लिए टैप करें
कमांड प्रॉम्प्ट या रन डायलॉग बॉक्स (Run Dialog Box) खोलने के लिए कौन सा शॉर्टकट है?
Windows Key + R
उत्तर देखने के लिए टैप करें
कंप्यूटर को लॉक करने या यूजर अकाउंट बदलने के लिए किस शॉर्टकट का उपयोग होता है?
Windows Key + L
उत्तर देखने के लिए टैप करें
Windows Settings (सेटिंग्स) को सीधे खोलने के लिए कौन सी कुंजी संयोजन उपयोग होती है?
Windows Key + I
उत्तर देखने के लिए टैप करें
खुली हुई एप्लीकेशनों के बीच स्विच करने या टास्क व्यू देखने के लिए क्या दबाया जाता है?
Windows Key + Tab
उत्तर देखने के लिए टैप करें
विभिन्न खुली हुई एप्लीकेशनों के बीच चक्र के रूप में आगे बढ़ने के लिए कौन सा शॉर्टकट है?
Alt + Tab
उत्तर देखने के लिए टैप करें
वर्तमान सक्रिय विंडो को तुरंत बंद करने या प्रोग्राम से बाहर निकलने के लिए क्या प्रयुक्त होता है?
Alt + F4
उत्तर देखने के लिए टैप करें
क्विक लिंक या पावर यूजर मेनू (Quick Link Menu) खोलने के लिए कौन सा शॉर्टकट है?
Windows Key + X
उत्तर देखने के लिए टैप करें
स्क्रीन का स्क्रीनशॉट लेने और उसे Snip & Sketch में खोलने के लिए कौन सा शॉर्टकट है?
Windows Key + Shift + S
उत्तर देखने के लिए टैप करें
पूर्ण स्क्रीन (Full Screen) मोड को चालू या बंद करने के लिए किस फंक्शन कुंजी का उपयोग किया जाता है?
F11
उत्तर देखने के लिए टैप करें
किसी वेबपेज या सक्रिय विंडो को रिफ्रेश (Refresh) करने के लिए कौन सी कुंजी दबाई जाती है?
F5
उत्तर देखने के लिए टैप करें
किसी भी सॉफ्टवेयर में सहायता या हेल्प (Help) विंडो खोलने के लिए कौन सी कुंजी प्रयोग होती है?
F1
उत्तर देखने के लिए टैप करें
चयनित फाइल या फोल्डर का नाम बदलने (Rename) के लिए किस फंक्शन की का उपयोग किया जाता है?
F2
उत्तर देखने के लिए टैप करें
किसी फाइल या फोल्डर में सर्च बार या फ़ाइल ढूँढने के लिए कौन सी कुंजी प्रयुक्त होती है?
F3
उत्तर देखने के लिए टैप करें
ब्राउज़र में एड्रेस बार पर कर्सर ले जाने या URL हाईलाइट करने के लिए क्या शॉर्टकट है?
Ctrl + L या Alt + D
उत्तर देखने के लिए टैप करें
वेब ब्राउज़र में एक नया टैब (New Tab) खोलने के लिए किस शॉर्टकट का उपयोग किया जाता है?
Ctrl + T
उत्तर देखने के लिए टैप करें
वेब ब्राउज़र में बंद किए गए अंतिम टैब को पुनः खोलने के लिए कौन सा शॉर्टकट है?
Ctrl + Shift + T
उत्तर देखने के लिए टैप करें
ब्राउज़र में इतिहास (History) पेज खोलने के लिए किस शॉर्टकट का प्रयोग होता है?
Ctrl + H
उत्तर देखने के लिए टैप करें
ब्राउज़र में डाउनलोड्स (Downloads) पेज खोलने के लिए कौन सा शॉर्टकट है?
Ctrl + J
उत्तर देखने के लिए टैप करें
वर्तमान वेबपेज को बुकमार्क (Bookmark) करने के लिए किस शॉर्टकट का उपयोग किया जाता है?
Ctrl + D
उत्तर देखने के लिए टैप करें
वेब ब्राउज़र में अगले टैब पर जाने के लिए कौन सा संयोजन प्रयुक्त होता है?
Ctrl + Tab
उत्तर देखने के लिए टैप करें
वेब ब्राउज़र में पिछले टैब पर जाने के लिए किस शॉर्टकट का उपयोग होता है?
Ctrl + Shift + Tab
उत्तर देखने के लिए टैप करें
डॉक्यूमेंट में कर्सर को सीधे लाइन के अंत (End of Line) में पहुँचाने के लिए कौन सी कुंजी है?
End
उत्तर देखने के लिए टैप करें
कर्सर को दस्तावेज या लाइन के बिल्कुल शुरुआत (Beginning) में पहुँचाने के लिए क्या दबाया जाता है?
Home
उत्तर देखने के लिए टैप करें
कर्सर को सीधे पूरे दस्तावेज़ के अंत में पहुँचाने के लिए किस शॉर्टकट का प्रयोग होता है?
Ctrl + End
उत्तर देखने के लिए टैप करें
कर्सर को सीधे पूरे दस्तावेज़ की शुरुआत में पहुँचाने के लिए कौन सा शॉर्टकट है?
Ctrl + Home
उत्तर देखने के लिए टैप करें
दस्तावेज़ में एक स्क्रीन ऊपर जाने के लिए किस कुंजी का उपयोग किया जाता है?
Page Up
उत्तर देखने के लिए टैप करें
दस्तावेज़ में एक स्क्रीन नीचे जाने के लिए कौन सी कुंजी प्रयुक्त होती है?
Page Down
उत्तर देखने के लिए टैप करें
किसी फाइल या फोल्डर को बिना रिसाइकल बिन में भेजे सीधे स्थायी रूप से हटाने के लिए क्या शॉर्टकट है?
Shift + Delete
उत्तर देखने के लिए टैप करें
चयनित आइटम के गुणधर्म (Properties) देखने के लिए कौन सा शॉर्टकट उपयोग होता है?
Alt + Enter
उत्तर देखने के लिए टैप करें
फाइल एक्सप्लोरर में एक नया फोल्डर बनाने के लिए कौन सा शॉर्टकट है?
Ctrl + Shift + N
उत्तर देखने के लिए टैप करें
टास्क मैनेजर (Task Manager) सीधे खोलने के लिए किस कीबोर्ड संयोजन का उपयोग होता है?
Ctrl + Shift + Esc
उत्तर देखने के लिए टैप करें
सिस्टम सुरक्षा विकल्प (Lock, Sign out, Task Manager आदि) खोलने के लिए क्या दबाया जाता है?
Ctrl + Alt + Del
उत्तर देखने के लिए टैप करें
टेक्स्ट संपादन के दौरान एक शब्द बाईं ओर चयन करने के लिए क्या शॉर्टकट है?
Ctrl + Shift + Left Arrow
उत्तर देखने के लिए टैप करें
टेक्स्ट संपादन के दौरान एक शब्द दाईं ओर चयन करने के लिए कौन सा शॉर्टकट है?
Ctrl + Shift + Right Arrow
उत्तर देखने के लिए टैप करें
किसी दस्तावेज में Save As डायलॉग बॉक्स खोलने के लिए कौन सी फंक्शन कुंजी प्रयुक्त होती है?
F12
उत्तर देखने के लिए टैप करें
वेब ब्राउज़र या दस्तावेज़ में ज़ूम इन (आकार बड़ा करने) के लिए कौन सा शॉर्टकट है?
Ctrl + Plus (+)
उत्तर देखने के लिए टैप करें
वेब ब्राउज़र या दस्तावेज़ में ज़ूम आउट (आकार छोटा करने) के लिए क्या शॉर्टकट है?
Ctrl + Minus (-)
उत्तर देखने के लिए टैप करें
ज़ूम स्तर को डिफ़ॉल्ट (100%) पर रीसेट करने के लिए कौन सा शॉर्टकट है?
Ctrl + 0
उत्तर देखने के लिए टैप करें
टेक्स्ट को बाईं ओर संरेखित (Left Align) करने के लिए कौन सा शॉर्टकट है?
Ctrl + L
उत्तर देखने के लिए टैप करें
टेक्स्ट को दाईं ओर संरेखित (Right Align) करने के लिए कौन सा शॉर्टकट है?
Ctrl + R
उत्तर देखने के लिए टैप करें
टेक्स्ट को मध्य में संरेखित (Center Align) करने के लिए क्या दबाया जाता है?
Ctrl + E
उत्तर देखने के लिए टैप करें
टेक्स्ट को जस्टिफ़ाई (Justify) करने के लिए किस शॉर्टकट का उपयोग होता है?
Ctrl + J
उत्तर देखने के लिए टैप करें
एक नया वर्चुअल डेस्कटॉप जोड़ने के लिए कौन सा शॉर्टकट है?
Windows Key + Ctrl + D
उत्तर देखने के लिए टैप करें
वर्तमान वर्चुअल डेस्कटॉप को बंद करने के लिए क्या शॉर्टकट है?
Windows Key + Ctrl + F4
उत्तर देखने के लिए टैप करें
विभिन्न वर्चुअल डेस्कटॉप के बीच बाईं ओर जाने के लिए कौन सा शॉर्टकट है?
Windows Key + Ctrl + Left Arrow
उत्तर देखने के लिए टैप करें
विभिन्न वर्चुअल डेस्कटॉप के बीच दाईं ओर जाने के लिए कौन सा शॉर्टकट है?
Windows Key + Ctrl + Right Arrow
उत्तर देखने के लिए टैप करें
टास्कबार में पिन किए गए ऐप्स को उनके क्रमांक (1 से 9) के अनुसार खोलने के लिए क्या उपयोग होता है?
Windows Key + [1-9 नंबर की]
उत्तर देखने के लिए टैप करें
इमोजी पैनल (Emoji Panel) खोलने के लिए किस शॉर्टकट का उपयोग किया जाता है?
Windows Key + . (Period) या Windows Key + Semicolon (;)
उत्तर देखने के लिए टैप करें
क्लिपबोर्ड हिस्ट्री (Clipboard History) देखने और प्रबंधित करने के लिए क्या शॉर्टकट है?
Windows Key + V

Windows Key + H

Alt + Right Arrow

Alt + Up Arrow
उत्तर देखने के लिए टैप करें

उत्तर देखने के लिए टैप करें
कर्सर के दाईं ओर के एक शब्द को हटाने के लिए किस शॉर्टकट का उपयोग किया जाता है?
Ctrl + Delete

F7

Ctrl + G

Windows Key + Left Arrow
उत्तर देखने के लिए टैप करें
सक्रिय विंडो को स्क्रीन के दाईं ओर स्नैप (Snap Right) करने के लिए कौन सा शॉर्टकट है?
Windows Key + Right Arrow
उत्तर देखने के लिए टैप करें
सक्रिय विंडो को मैक्सिमाइज करने या ऊपर स्नैप करने के लिए क्या शॉर्टकट है?
Windows Key + Up Arrow
उत्तर देखने के लिए टैप करें
सक्रिय विंडो को मिनिमाइज करने या नीचे स्नैप करने के लिए कौन सा शॉर्टकट है?
Windows Key + Down Arrow
उत्तर देखने के लिए टैप करें
किसी ब्राउज़र में वर्तमान पृष्ठ को रिलोड या पुनः लोड करने के लिए F5 के अलावा कौन सा शॉर्टकट है?
Ctrl + R
उत्तर देखने के लिए टैप करें
ब्राउज़र में कैश को नजरअंदाज करते हुए पेज को हार्ड रिफ्रेश करने के लिए क्या शॉर्टकट है?
Ctrl + F5 या Ctrl + Shift + R
उत्तर देखने के लिए टैप करें
किसी खुले हुए डॉक्यूमेंट में हाइपरलिंक डालने के लिए कौन सा शॉर्टकट उपयोग होता है?
Ctrl + K
उत्तर देखने के लिए टैप करें

Ctrl + 1
उत्तर देखने के लिए टैप करें
टेक्स्ट की लाइन के बीच डबल स्पेसिंग लागू करने के लिए कौन सा शॉर्टकट है?
Ctrl + 2
उत्तर देखने के लिए टैप करें

Ctrl + 5
उत्तर देखने के लिए टैप करें

Shift + Enter

Ctrl + ; (Semicolon)
उत्तर देखने के लिए टैप करें
एक्सेल या डेटा शीट में वर्तमान समय (Current Time) दर्ज करने के लिए कौन सा शॉर्टकट है?
Ctrl + Shift + : (Colon)
उत्तर देखने के लिए टैप करें
विंडोज में प्रोजेक्ट या डिस्प्ले मोड (जैसे दूसरी स्क्रीन पर डुप्लीकेट या एक्सटेंड करना) खोलने के लिए क्या शॉर्टकट है?
Windows Key + P

Up Arrow Key
