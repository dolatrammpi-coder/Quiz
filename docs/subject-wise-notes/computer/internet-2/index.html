Internet 2

World Wide Web, DNS, HTTP/HTTPS, ईमेल, सर्च इंजन एवं सुरक्षित इंटरनेट उपयोग

One-Liner Questions

World Wide Web (WWW) का विकास किस वर्ष और किसके द्वारा किया गया था?
1989 में टिम बर्नर्स-ली (Tim Berners-Lee) द्वारा CERN (स्विट्जरलैंड) में किया गया था।
उत्तर देखने के लिए टैप करें
World Wide Web (WWW) और इंटरनेट में बुनियादी अंतर क्या है?
इंटरनेट नेटवर्क का एक भौतिक बुनियादी ढांचा (Infrastructure) है, जबकि WWW एक सॉफ्टवेयर सेवा है जो इंटरनेट पर हाइपरटेक्स्ट दस्तावेजों को एक्सेस करने की सुविधा देती है।
उत्तर देखने के लिए टैप करें
WWW का संचालन मुख्य रूप से किन तीन प्रमुख तकनीकों (Components) पर आधारित है?
HTML, HTTP/HTTPS, और URL/URI
उत्तर देखने के लिए टैप करें
W3C (World Wide Web Consortium) का मुख्य कार्य क्या है?
वेब मानकों (Web Standards) और प्रोटोकॉल का निर्धारण एवं रखरखाव करना
उत्तर देखने के लिए टैप करें
W3C की स्थापना किस वर्ष हुई थी और इसके संस्थापक कौन थे?
1994 में टिम बर्नर्स-ली द्वारा
उत्तर देखने के लिए टैप करें
हाइपरटेक्स्ट (Hypertext) की अवधारणा का श्रेय किसे दिया जाता है?
टेड नेल्सन (Ted Nelson) को (1960 के दशक में)
उत्तर देखने के लिए टैप करें
वेब पेज (Web Page) क्या है और यह किस भाषा में लिखा जाता है?
इंटरनेट पर उपलब्ध एक इलेक्ट्रॉनिक दस्तावेज, जो मुख्य रूप से HTML (HyperText Markup Language) में लिखा जाता है।
उत्तर देखने के लिए टैप करें
स्टैटिक (Static) और डायनेमिक (Dynamic) वेब पेज में क्या अंतर है?
स्टैटिक वेब पेज का कंटेंट सभी उपयोगकर्ताओं के लिए समान रहता है, जबकि डायनेमिक वेब पेज का कंटेंट यूजर इनपुट या सर्वर डेटाबेस के आधार पर बदलता है।
उत्तर देखने के लिए टैप करें
वेबसाइट (Website) की तकनीकी परिभाषा क्या है?
परस्पर जुड़े हुए वेब पेजों (Web Pages) का संग्रह जो किसी एक डोमेन नेम के अंतर्गत होस्ट किया जाता है।
उत्तर देखने के लिए टैप करें
होम पेज (Home Page) किसे कहा जाता है?
किसी वेबसाइट का मुख्य या पहला खुलने वाला पेज
उत्तर देखने के लिए टैप करें
वेब सर्वर (Web Server) का प्राथमिक कार्य क्या है?
HTTP/HTTPS प्रोटोकॉल के माध्यम से वेब पेजों को क्लाइंट (वेब ब्राउज़र) तक पहुंचाना
उत्तर देखने के लिए टैप करें
वेब ब्राउज़र (Web Browser) किस प्रकार का सॉफ्टवेयर है?
एक एप्लीकेशन सॉफ्टवेयर (Application Software) जो वेब क्लाइंट के रूप में कार्य करता है।
उत्तर देखने के लिए टैप करें
विश्व का पहला ग्राफिकल वेब ब्राउज़र कौन सा था?
मोज़ेक (Mosaic), जिसे 1993 में मार्क एंड्रीसन द्वारा विकसित किया गया था।
उत्तर देखने के लिए टैप करें
पहला टेक्स्ट-बेस्ड (Text-based) वेब ब्राउज़र कौन सा था?
लिंक्स (Lynx)
उत्तर देखने के लिए टैप करें
URI (Uniform Resource Identifier) और URL (Uniform Resource Locator) में क्या संबंध है?
URL, URI का ही एक विशिष्ट प्रकार है जो संसाधन के पहचानकर्ता के साथ-साथ उसके एक्सेस स्थान को भी निर्दिष्ट करता है।
उत्तर देखने के लिए टैप करें
URL के मुख्य भाग कौन-कौन से होते हैं?
प्रोटोकॉल (Scheme), डोमेन नेम/होस्ट, पोर्ट नंबर (वैकल्पिक), और फ़ाइल पाथ (Path)
उत्तर देखने के लिए टैप करें
URL `https://www.example.com/index.html` में `https` क्या दर्शाता है?
संचार प्रोटोकॉल (Communication Protocol)
उत्तर देखने के लिए टैप करें
URL में पोर्ट नंबर का उपयोग क्यों किया जाता है?
सर्वर पर विशिष्ट नेटवर्क सेवा या प्रक्रिया (Process) की पहचान करने के लिए
उत्तर देखने के लिए टैप करें
डोमेन नेम (Domain Name) क्या है?
इंटरनेट पर किसी वेबसाइट का मानव-पठनीय (Human-readable) अद्वितीय पता
उत्तर देखने के लिए टैप करें
डोमेन नेम और IP एड्रेस के बीच क्या संबंध है?
डोमेन नेम, जटिल न्यूमेरिक IP एड्रेस का एक टेक्स्ट-आधारित विकल्प है जिसे DNS द्वारा IP में बदला जाता है।
उत्तर देखने के लिए टैप करें
TLD (Top-Level Domain) का क्या अर्थ है?
डोमेन नेम का अंतिम भाग (जैसे `.com`, `.org`, `.gov`)
उत्तर देखने के लिए टैप करें
ccTLD (Country Code Top-Level Domain) का क्या अर्थ है? भारत का ccTLD क्या है?
किसी विशिष्ट देश या भौगोलिक क्षेत्र का प्रतिनिधित्व करने वाला TLD; भारत का ccTLD `.in` है।
उत्तर देखने के लिए टैप करें
gTLD (Generic Top-Level Domain) के तीन प्रमुख उदाहरण दें।
`.com` (व्यावसायिक), `.org` (गैर-लाभकारी संगठन), `.edu` (शैक्षणिक संस्थान)
उत्तर देखने के लिए टैप करें
gTLD `.mil` और `.gov` किन संस्थानों के लिए आरक्षित हैं?
`.mil` सैन्य संस्थाओं के लिए और `.gov` सरकारी एजेंसियों के लिए
उत्तर देखने के लिए टैप करें
DNS (Domain Name System) को इंटरनेट की दुनिया में क्या कहा जाता है?
इंटरनेट की फोनबुक (Phonebook of the Internet)
उत्तर देखने के लिए टैप करें
DNS का मुख्य तकनीकी कार्य क्या है?
डोमेन नेम (जैसे `google.com`) को IP एड्रेस (जैसे `142.250.190.46`) में अनुवादित (Translate) करना
उत्तर देखने के लिए टैप करें
DNS रिजॉल्यूशन (Resolution) की प्रक्रिया में कौन सा प्रोटोकॉल पोर्ट उपयोग होता है?
UDP पोर्ट 53 (सामान्यतः) और TCP पोर्ट 53 (बड़े डेटा ट्रांसफर के लिए)
उत्तर देखने के लिए टैप करें
DNS कैशिंग (DNS Caching) का मुख्य उद्देश्य क्या है?
DNS लुकअप समय को कम करना और नेटवर्क ट्रैफिक को घटाना
उत्तर देखने के लिए टैप करें
DNS सर्वर के चार मुख्य प्रकार कौन-कौन से हैं?
DNS Recursor, Root Name Server, TLD Name Server, और Authoritative Name Server
उत्तर देखने के लिए टैप करें
DNS Lookup की प्रक्रिया में Root Server की भूमिका क्या है?
क्लाइंट को संबंधित TLD Server का पता बताना
उत्तर देखने के लिए टैप करें
HTTP (Hypertext Transfer Protocol) किस नेटवर्क लेयर का प्रोटोकॉल है?
एप्लीकेशन लेयर (Application Layer)
उत्तर देखने के लिए टैप करें
HTTP की मुख्य विशेषता 'Stateless Protocol' होने का क्या अर्थ है?
सर्वर पूर्ववर्ती क्लाइंट अनुरोधों (Previous Requests) का कोई डेटा या स्थिति बनाए नहीं रखता।
उत्तर देखने के लिए टैप करें
HTTP डिफॉल्ट रूप से किस TCP पोर्ट का उपयोग करता है?
पोर्ट 80 (Port 80)
उत्तर देखने के लिए टैप करें
HTTPS (Hypertext Transfer Protocol Secure) में 'S' का क्या अर्थ है और यह कैसे सुरक्षा प्रदान करता है?
Secure; यह SSL/TLS एन्क्रिप्शन का उपयोग करके डेटा को सुरक्षित करता है।
उत्तर देखने के लिए टैप करें
HTTPS किस TCP पोर्ट का उपयोग करता है?
पोर्ट 443 (Port 443)
उत्तर देखने के लिए टैप करें
HTTP और HTTPS में सबसे मुख्य अंतर क्या है?
HTTP प्लेन टेक्स्ट में डेटा भेजता है (असुरक्षित), जबकि HTTPS एन्क्रिप्टेड डेटा भेजता है (सुरक्षित)।
उत्तर देखने के लिए टैप करें
SSL (Secure Sockets Layer) का अद्यतन और अधिक सुरक्षित रूप कौन सा है?
TLS (Transport Layer Security)
उत्तर देखने के लिए टैप करें
HTTP Request Methods में GET और POST में क्या मुख्य अंतर है?
GET का उपयोग सर्वर से डेटा प्राप्त करने के लिए होता है (डेटा URL में दिखता है), जबकि POST का उपयोग सर्वर पर डेटा भेजने के लिए होता है (डेटा बॉडी में सुरक्षित रहता है)।
उत्तर देखने के लिए टैप करें
HTTP स्टेटस कोड 404 का क्या अर्थ है?
Page Not Found (अनुरोधित संसाधन सर्वर पर नहीं मिला)
उत्तर देखने के लिए टैप करें
HTTP स्टेटस कोड 200 और 500 क्या दर्शाते हैं?
200 = Success (अनुरोध सफल), 500 = Internal Server Error (सर्वर में आंतरिक त्रुटि)
उत्तर देखने के लिए टैप करें
वेब कुकीज़ (Web Cookies) क्या हैं?
उपयोगकर्ता के वेब ब्राउज़र में सर्वर द्वारा संग्रहीत छोटी टेक्स्ट फ़ाइलें जो सत्र (Session) की स्थिति और प्राथमिकताओं को याद रखती हैं।
उत्तर देखने के लिए टैप करें
सेशन कुकी (Session Cookie) और पर्सिस्टेंट कुकी (Persistent Cookie) में क्या अंतर है?
सेशन कुकी ब्राउज़र बंद होते ही नष्ट हो जाती है, जबकि पर्सिस्टेंट कुकी एक निर्धारित तिथि तक हार्ड ड्राइव में संग्रहीत रहती है।
उत्तर देखने के लिए टैप करें
ई-मेल (Electronic Mail) का आविष्कारक किसे माना जाता है?
रे टॉमलिंसन (Ray Tomlinson) को (1971 में)
उत्तर देखने के लिए टैप करें
ई-मेल पते में '@' प्रतीक का चयन सबसे पहले किसने किया था?
रे टॉमलिंसन ने
उत्तर देखने के लिए टैप करें
ई-मेल एड्रेस के दो मुख्य भाग कौन से होते हैं?
यूज़रनेम (Username) और डोमेन नेम (Domain Name), जो '@' चिन्ह से अलग होते हैं।
उत्तर देखने के लिए टैप करें
ई-मेल भेजने के लिए मुख्य रूप से किस प्रोटोकॉल का उपयोग किया जाता है?
SMTP (Simple Mail Transfer Protocol)
उत्तर देखने के लिए टैप करें
SMTP का डिफॉल्ट नॉन-एन्क्रिप्टेड और एन्क्रिप्टेड (SSL/TLS) पोर्ट नंबर क्या है?
नॉन-एन्क्रिप्टेड: पोर्ट 25 (या 587); एन्क्रिप्टेड: पोर्ट 465
उत्तर देखने के लिए टैप करें
ई-मेल प्राप्त करने (Retrieve/Receive) के लिए किन दो मुख्य प्रोटोकॉल का उपयोग किया जाता है?
POP3 (Post Office Protocol version 3) और IMAP (Internet Message Access Protocol)
उत्तर देखने के लिए टैप करें
POP3 और IMAP में मुख्य अंतर क्या है?
POP3 ईमेल को स्थानीय डिवाइस पर डाउनलोड कर सर्वर से हटा देता है, जबकि IMAP ईमेल को सर्वर पर ही सिंक रखता है जिससे multiple डिवाइस से एक्सेस संभव होता है।
उत्तर देखने के लिए टैप करें
POP3 का मानक TCP पोर्ट नंबर क्या है?
पोर्ट 110 (SSL के लिए 995)
उत्तर देखने के लिए टैप करें
IMAP का मानक TCP पोर्ट नंबर क्या है?
पोर्ट 143 (SSL के लिए 993)
उत्तर देखने के लिए टैप करें
ई-मेल हेडर में CC और BCC का क्या अर्थ है?
CC = Carbon Copy, BCC = Blind Carbon Copy
उत्तर देखने के लिए टैप करें
BCC का मुख्य उपयोग और लाभ क्या है?
प्राप्तकर्ताओं की पहचान गोपनीय रखना; BCC में रखे गए प्राप्तकर्ता को अन्य कोई प्राप्तकर्ता नहीं देख सकता।
उत्तर देखने के लिए टैप करें
MIME (Multipurpose Internet Mail Extensions) प्रोटोकॉल की क्या भूमिका है?
गैर-टेक्स्ट फाइलों (जैसे फोटो, ऑडियो, वीडियो, पीडीएफ) को ईमेल के साथ अटैचमेंट के रूप में भेजने की अनुमति देना
उत्तर देखने के लिए टैप करें
स्पैम ईमेल (Spam Email) को अन्य किस नाम से जाना जाता है?
Junk Email या UCE (Unsolicited Bulk Email)
उत्तर देखने के लिए टैप करें
सर्च इंजन (Search Engine) का मुख्य कार्य क्या है?
वर्ल्ड वाइड वेब पर उपलब्ध विशाल जानकारी में से उपयोगकर्ता के कीवर्ड के अनुसार प्रासंगिक सामग्री खोजना
उत्तर देखने के लिए टैप करें
विश्व का पहला वेब सर्च इंजन कौन सा माना जाता है?
आर्ची (Archie), जिसे 1990 में एलन एम्टेज द्वारा विकसित किया गया था।
उत्तर देखने के लिए टैप करें
सर्च इंजन की कार्यप्रणाली के तीन प्रमुख चरण कौन-कौन से हैं?
Crawling (क्रॉलिंग), Indexing (इंडेक्सिंग), और Ranking/Serving (रैंकिंग)
उत्तर देखने के लिए टैप करें
सर्च इंजन में 'वेब क्रॉलर' (Web Crawler) या 'स्पाइडर' (Spider) की क्या भूमिका है?
वेब पेजों पर जाकर नए और अद्यतन कंटेंट के लिंक्स का स्वतः अवलोकन करना
उत्तर देखने के लिए टैप करें
सर्च इंजन में 'इंडेक्सिंग' (Indexing) प्रक्रिया का क्या अर्थ है?
क्रॉल किए गए पेजों के डेटा को एक विशाल डेटाबेस (Index) में व्यवस्थित और संग्रहित करना
उत्तर देखने के लिए टैप करें
गूगल सर्च इंजन में इस्तेमाल होने वाले प्रसिद्ध रैंकिंग एल्गोरिदम का नाम क्या था?
पेजफाइंड/पेजरैंक (PageRank), जिसे लैरी पेज और सर्गेई ब्रिन ने विकसित किया था।
उत्तर देखने के लिए टैप करें
गूगल (Google), बाइडू (Baidu), और यांडेक्स (Yandex) क्रमशः किन देशों के प्रमुख सर्च इंजन हैं?
गूगल = अमेरिका, बाइडू = चीन, यांडेक्स = रूस
उत्तर देखने के लिए टैप करें
डकडकगो (DuckDuckGo) सर्च इंजन की मुख्य विशेषता क्या है?
उपयोगकर्ताओं की गोपनीयता (Privacy) की रक्षा करना और सर्च हिस्ट्री को ट्रैक न करना
उत्तर देखने के लिए टैप करें
मेटा-सर्च इंजन (Meta-Search Engine) किसे कहते हैं?
वह सर्च इंजन जो अपना स्वयं का डेटाबेस बनाने के बजाय अन्य कई सर्च इंजनों के परिणामों को मिलाकर दिखाता है (उदा. Dogpile)।
उत्तर देखने के लिए टैप करें
सर्च इंजन में बुलियन ऑपरेटर्स (Boolean Operators) AND, OR, NOT का प्रयोग क्यों किया जाता है?
सर्च परिणामों को अधिक सटीक और सीमित या विस्तृत बनाने के लिए
उत्तर देखने के लिए टैप करें
सर्च में उद्धरण चिन्हों (`" "`) का प्रयोग करने से क्या होता है?
सर्च इंजन केवल उसी सटीक वाक्यांश (Exact Phrase) वाले परिणाम दिखाता है।
उत्तर देखने के लिए टैप करें
VoIP (Voice over Internet Protocol) का प्राथमिक उपयोग क्या है?
पारंपरिक टेलीफोन लाइनों के बजाय एनालॉग ऑडियो संकेतों को डिजिटल डेटा में बदलकर इंटरनेट पर संचार कराना
उत्तर देखने के लिए टैप करें
VoIP में मुख्य रूप से किस सिग्नलिंग प्रोटोकॉल का उपयोग किया जाता है?
SIP (Session Initiation Protocol)
उत्तर देखने के लिए टैप करें
इन्स्टेंट मैसेजिंग (Instant Messaging - IM) और ईमेल संचार में प्राथमिक अंतर क्या है?
IM में रीयल-टाइम (तत्काल) टेक्स्ट संचार होता है, जबकि ईमेल एक असिंक्रोनस (Store-and-Forward) संचार माध्यम है।
उत्तर देखने के लिए टैप करें
FTP (File Transfer Protocol) का उपयोग किसलिए किया जाता है और यह किन दो पोर्ट्स का उपयोग करता है?
नेटवर्क पर फाइलों को अपलोड/डाउनलोड करने के लिए; पोर्ट 20 (डेटा ट्रांसफर) और पोर्ट 21 (कंट्रोल सिग्नल)
उत्तर देखने के लिए टैप करें
SFTP (SSH File Transfer Protocol) और FTPS में क्या अंतर है?
SFTP, SSH प्रोटोकॉल पर कार्य करता है (पोर्ट 22), जबकि FTPS, SSL/TLS एन्क्रिप्शन का उपयोग करता है।
उत्तर देखने के लिए टैप करें
टेलनेट (Telnet) क्या है और इसकी मुख्य सुरक्षा खामी क्या है?
रिमोट लॉगिन प्रोटोकॉल; यह डेटा को प्लेन टेक्स्ट (Plain Text) में भेजता है, जिससे यह असुरक्षित है।
उत्तर देखने के लिए टैप करें
Telnet के स्थान पर वर्तमान में किस सुरक्षित रिमोट एक्सेस प्रोटोकॉल का प्रयोग किया जाता है?
SSH (Secure Shell) - पोर्ट 22
उत्तर देखने के लिए टैप करें
IRC (Internet Relay Chat) किस प्रकार की सेवा है?
एक टेक्स्ट-आधारित रीयल-टाइम ऑनलाइन चैट प्रोटोकॉल
उत्तर देखने के लिए टैप करें
क्लाउड कंप्यूटिंग (Cloud Computing) में IaaS, PaaS, और SaaS का पूरा नाम क्या है?
IaaS = Infrastructure as a Service, PaaS = Platform as a Service, SaaS = Software as a Service
उत्तर देखने के लिए टैप करें
गूगल ड्राइव (Google Drive) और ड्रॉपबॉक्स (Dropbox) किस प्रकार की इंटरनेट सेवा के उदाहरण हैं?
क्लाउड स्टोरेज सेवा (Cloud Storage Services)
उत्तर देखने के लिए टैप करें
ई-कॉमर्स के मुख्य मॉडल B2B, B2C, और C2C का क्या अर्थ है?
B2B = Business to Business, B2C = Business to Consumer, C2C = Consumer to Consumer
उत्तर देखने के लिए टैप करें
ओएलएक्स (OLX) या ई-बे (eBay) पर ग्राहकों के बीच खरीद-बिक्री ई-कॉमर्स के किस मॉडल का उदाहरण है?
C2C (Consumer to Consumer)
उत्तर देखने के लिए टैप करें
इंटरनेट आधारित ई-लर्निंग (E-Learning) में MOOC का पूर्ण रूप क्या है?
Massive Open Online Course
उत्तर देखने के लिए टैप करें
इंटरनेट का मुख्य व्यावसायिक और सामाजिक लाभ क्या है?
वैश्विक संचार की गति में वृद्धि, सूचना तक त्वरित पहुँच, और ई-गवर्नेंस एवं ई-कॉमर्स की सुविधा
उत्तर देखने के लिए टैप करें
डिजिटल डिवाइड (Digital Divide) की अवधारणा क्या दर्शाती है?
सूचना एवं संचार तकनीक (ICT) तक पहुँच रखने वाले और इससे वंचित लोगों/क्षेत्रों के बीच की असमानता
उत्तर देखने के लिए टैप करें
नेट न्यूट्रैलिटी (Net Neutrality) का मूल सिद्धांत क्या है?
इंटरनेट सेवा प्रदाताओं (ISPs) द्वारा सभी इंटरनेट डेटा को समान व्यवहार देना, बिना किसी वेबसाइट/सेवा को ब्लॉक या धीमा किए।
उत्तर देखने के लिए टैप करें
फायरवॉल (Firewall) का मुख्य सुरक्षा कार्य क्या है?
पूर्व-निर्धारित सुरक्षा नियमों के आधार पर आने वाले (Inbound) और जाने वाले (Outbound) नेटवर्क ट्रैफिक की निगरानी और नियंत्रण करना
उत्तर देखने के लिए टैप करें
फायरवॉल किन दो रूपों में उपलब्ध हो सकता है?
सॉफ्टवेयर और हार्डवेयर दोनों रूपों में
उत्तर देखने के लिए टैप करें
फिशिंग (Phishing) साइबर हमला क्या है?
विश्वासघाती ईमेल या फर्जी वेबसाइटों के जरिए उपयोगकर्ताओं के संवेदनशील विवरण (पासवर्ड, कार्ड नंबर) चुराना
उत्तर देखने के लिए टैप करें
विशिंग (Vishing) और स्मिशिंग (Smishing) में क्या अंतर है?
विशिंग फोन कॉल (Voice) के जरिए और स्मिशिंग SMS मैसेज के जरिए की जाने वाली फिशिंग है।
उत्तर देखने के लिए टैप करें
मैन-इन-द-मिडिल (MitM) अटैक क्या होता है?
जहाँ हमलावर दो पक्षों के बीच हो रहे संचार को चुपके से रोकता है और बदल देता है।
उत्तर देखने के लिए टैप करें
मैलवेयर (Malware) का क्या अर्थ है और इसके तीन प्रकार बताएं?
Malicious Software; प्रकार: वायरस (Virus), वर्म (Worm), और ट्रोजन हॉर्स (Trojan Horse)
उत्तर देखने के लिए टैप करें
कंप्यूटर वायरस और वर्म (Worm) में बुनियादी अंतर क्या है?
वायरस को फैलने के लिए होस्ट फ़ाइल की आवश्यकता होती है, जबकि वर्म स्वयं की प्रतियां बनाकर स्वतंत्र रूप से फैलता है।
उत्तर देखने के लिए टैप करें
ट्रोजन हॉर्स (Trojan Horse) मैलवेयर की पहचान क्या है?
यह एक उपयोगी सॉफ्टवेयर प्रतीत होता है लेकिन पृष्ठभूमि में दुर्भावनापूर्ण कार्य करता है।
उत्तर देखने के लिए टैप करें
रैनसमवेयर (Ransomware) साइबर हमले का मुख्य उद्देश्य क्या होता है?
उपयोगकर्ता की फाइलों को एन्क्रिप्ट कर देना और उन्हें अनलॉक करने के लिए फिरौती (Ransom) मांगना
उत्तर देखने के लिए टैप करें
स्पाइवेयर (Spyware) क्या है और इसका एक सामान्य उदाहरण क्या है?
उपयोगकर्ता की जानकारी के बिना उसकी गतिविधियों पर नज़र रखने वाला मैलवेयर; उदाहरण: कीलॉगर (Keylogger)
उत्तर देखने के लिए टैप करें
DDoS (Distributed Denial of Service) अटैक का नेटवर्क पर क्या प्रभाव पड़ता है?
कई संक्रमित सिस्टमों से अत्यधिक ट्रैफिक भेजकर लक्षित सर्वर को ठप कर देना
उत्तर देखने के लिए टैप करें
CAPTCHA का पूर्ण रूप क्या है और इसका उपयोग क्यों किया जाता है?
Completely Automated Public Turing test to tell Computers and Humans Apart; स्वचालित बॉट्स को रोकने के लिए
उत्तर देखने के लिए टैप करें
VPN (Virtual Private Network) का प्राथमिक सुरक्षा उपयोग क्या है?
पब्लिक नेटवर्क पर एक सुरक्षित, एन्क्रिप्टेड टनल बनाकर उपयोगकर्ता की पहचान और IP एड्रेस को छुपाना
उत्तर देखने के लिए टैप करें
टू-फैक्टर ऑथेंटिकेशन (2FA) सुरक्षा को कैसे मजबूत बनाता है?
केवल पासवर्ड ही नहीं, बल्कि एक अतिरिक्त कारक (जैसे OTP या बायोमेट्रिक) की मांग करके
उत्तर देखने के लिए टैप करें
डिजिटल हस्ताक्षर (Digital Signature) किस सिद्धांत पर कार्य करता है?
असsymmetric क्रिप्टोग्राफी (Private Key द्वारा साइन और Public Key द्वारा वेरिफिकेशन)
उत्तर देखने के लिए टैप करें
डिजिटल प्रमाणपत्र (Digital Certificate) जारी करने वाली संस्था को क्या कहा जाता है?
सर्टिफाइंग अथॉरिटी (CA - Certifying Authority)
उत्तर देखने के लिए टैप करें
साइबर हाइजीन (Cyber Hygiene) से क्या तात्पर्य है?
ऑनलाइन सुरक्षा बनाए रखने के लिए नियमित रूप से अपनाए जाने वाले सुरक्षित अभ्यास (जैसे मजबूत पासवर्ड, नियमित अपडेट)
उत्तर देखने के लिए टैप करें
भारत में साइबर अपराध और सूचना प्रौद्योगिकी से संबंधित प्राथमिक कानून कौन सा है?
सूचना प्रौद्योगिकी अधिनियम, 2000 (IT Act, 2000)
उत्तर देखने के लिए टैप करें
IT Act, 2000 की कौन सी धारा हैकिंग और कंप्यूटर सिस्टम में अनधिकृत पहुंच से संबंधित है?
धारा 66 (Section 66)
उत्तर देखने के लिए टैप करें
CERT-In का पूर्ण रूप क्या है और भारत में इसकी क्या भूमिका है?
Indian Computer Emergency Response Team; यह भारत में साइबर सुरक्षा घटनाओं का जवाब देने वाली राष्ट्रीय नोडल एजेंसी है।
उत्तर देखने के लिए टैप करें
डार्क वेब (Dark Web) और डीप वेब (Deep Web) में क्या अंतर है?
डीप वेब वह सामग्री है जो सर्च इंजन द्वारा इंडेक्स नहीं की जाती (उदा. ईमेल, बैंकिंग); डार्क वेब डीप वेब का वह भाग है जिसे एक्सेस करने के लिए विशेष सॉफ्टवेयर (जैसे Tor) की आवश्यकता होती है।
उत्तर देखने के लिए टैप करें
टॉर (Tor) ब्राउज़र का पूर्ण रूप क्या है और यह क्या सुविधा देता है?
The Onion Router; यह इंटरनेट पर अनाम (Anonymous) ब्राउज़िंग की सुविधा देता है।
उत्तर देखने के लिए टैप करें
कुकी पूँछ/ट्रैकिंग (Cookie Tracking) को रोकने के लिए ब्राउज़र में किस मोड का उपयोग किया जाता है?
इन्कॉग्निटो/प्राइवेट ब्राउज़िंग मोड (Incognito / Private Browsing Mode)
उत्तर देखने के लिए टैप करें
क्रॉस-साइट स्क्रिप्टिंग (XSS) अटैक किस प्रकार का हमला है?
जहाँ हमलावर एक विश्वसनीय वेबसाइट में दुर्भावनापूर्ण क्लाइंट-साइड स्क्रिप्ट इंजेक्ट करता है।
उत्तर देखने के लिए टैप करें
SQL इंजेक्शन (SQLi) अटैक का प्राथमिक लक्ष्य क्या होता है?
डेटाबेस में हेरफेर करने के लिए अनधिकृत SQL कमांड्स इंजेक्ट करना
उत्तर देखने के लिए टैप करें
जीरो-डे वल्नरेबिलिटी (Zero-day Vulnerability) से क्या तात्पर्य है?
सॉफ्टवेयर में एक ऐसी सुरक्षा खामी जिसके बारे में डेवलपर को पता नहीं होता और उसके लिए कोई पैच उपलब्ध नहीं होता

वेब ब्राउज़र द्वारा सही वेब सर्वर तक पहुँचने के लिए
HTTP / HTTPS
उत्तर देखें
क्लाइंट और वेब सर्वर के बीच डेटा ट्रांसफर प्रोटोकॉल
उत्तर देखें
वेब पेजों को सुरक्षित एवं असुरक्षित रूप से लोड करना
URL (Uniform Resource Locator)
उत्तर देखें
वेब पर किसी संसाधन का विशिष्ट पता निर्दिष्ट करना
उत्तर देखें
वेबपेज, फ़ाइल या मीडिया तक सीधे पहुँच बनाना
SMTP
उत्तर देखें
ई-मेल संदेशों को सर्वर तक या सर्वर के बीच भेजना
उत्तर देखें
आउटगोइंग ई-मेल संचार
POP3 / IMAP
उत्तर देखें
मेल सर्वर से ई-मेल प्राप्त करना एवं प्रबंधित करना
उत्तर देखें
इनकमिंग ई-मेल एक्सेस (POP3 लोकल स्टोरेज, IMAP सर्वर सिंक)
वेब क्रॉलर (Spider)
उत्तर देखें
सर्च इंजन हेतु नए व अपडेटेड वेब पेजों को खोजना
उत्तर देखें
वेब सामग्री की इंडेक्सिंग और रैंकिंग में
VPN (Virtual Private Network)
उत्तर देखें
एन्क्रिप्टेड नेटवर्क टनल बनाकर गोपनीयता प्रदान करना
उत्तर देखें
सुरक्षित रिमोट एक्सेस एवं पहचान छिपाने हेतु
फायरवॉल (Firewall)
उत्तर देखें
अनाधिकृत नेटवर्क ट्रैफिक को रोकना एवं निगरानी करना
उत्तर देखें
आंतरिक नेटवर्क और इंटरनेट के बीच सुरक्षा दीवार
SSL / TLS
उत्तर देखें
डेटा ट्रांसफर के दौरान क्रिप्टोग्राफिक सुरक्षा देना
उत्तर देखें
ई-कॉमर्स, ऑनलाइन बैंकिंग एवं HTTPS सुरक्षित कनेक्शन में
VoIP
उत्तर देखें
इंटरनेट के माध्यम से वॉयस/वीडियो कॉल संचालित करना
उत्तर देखें
डिजिटल वॉयस कम्यूनिकेशन (उदा. Skype, WhatsApp Call)
