One-Liner Questions

माइक्रोसॉफ्ट वर्ड में चयनित टेक्स्ट की फ़ॉर्मेटिंग कॉपी करने के लिए किस शॉर्टकट का उपयोग किया जाता है?
Ctrl + Shift + C
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में कॉपी की गई फ़ॉर्मेटिंग को अन्य टेक्स्ट पर लागू (Paste Format) करने के लिए क्या शॉर्टकट है?
Ctrl + Shift + V
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में चयनित टेक्स्ट पर डबल अंडरलाइन (Double Underline) लागू करने के लिए कौन सा शॉर्टकट है?
Ctrl + Shift + D
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में केवल शब्दों के नीचे रेखा खींचने (Words Only Underline) के लिए क्या शॉर्टकट है?
Ctrl + Shift + W
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में चयनित टेक्स्ट को स्मॉल कैप्स (Small Capitals) में बदलने के लिए कौन सा शॉर्टकट प्रयुक्त होता है?
Ctrl + Shift + K
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में चयनित टेक्स्ट को सभी कैपिटल अक्षरों (All Caps) में बदलने के लिए क्या शॉर्टकट है?
Ctrl + Shift + A
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में बुलेटेड लिस्ट (List Bullet style) लागू करने के लिए कौन सा शॉर्टकट है?
Ctrl + Shift + L
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में 'Apply Styles' टास्क पेन खोलने के लिए किस शॉर्टकट का उपयोग किया जाता है?
Ctrl + Shift + S
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में कॉपीराइट प्रतीक (©) दर्ज करने के लिए कौन सा कीबोर्ड शॉर्टकट है?
Ctrl + Alt + C
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में रजिस्टर्ड ट्रेडमार्क प्रतीक (®) दर्ज करने के लिए क्या शॉर्टकट है?
Ctrl + Alt + R
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में ट्रेडमार्क प्रतीक (™) दर्ज करने के लिए कौन सा शॉर्टकट उपयोग होता है?
Ctrl + Alt + T
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में दस्तावेज़ में टिप्पणी (Comment) जोड़ने के लिए कौन सा शॉर्टकट है?
Ctrl + Alt + M
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में ट्रैक चेंजेज (Track Changes) को चालू या बंद करने के लिए क्या शॉर्टकट है?
Ctrl + Shift + E
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में वर्तमान तारीख (Current Date) डालने के लिए कौन सा शॉर्टकट प्रयुक्त होता है?
Alt + Shift + D
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में वर्तमान समय (Current Time) डालने के लिए क्या शॉर्टकट है?
Alt + Shift + T
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में फॉन्ट बदलने वाली विंडो या बॉक्स खोलने के लिए कौन सा शॉर्टकट है?
Ctrl + Shift + F
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में फॉन्ट का आकार बदलने के लिए कौन सा शॉर्टकट उपयोग होता है?
Ctrl + Shift + P
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में चयनित टेक्स्ट का फॉन्ट आकार एक पॉइंट घटाने के लिए क्या शॉर्टकट है?
Ctrl + [
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में चयनित टेक्स्ट का फॉन्ट आकार एक पॉइंट बढ़ाने के लिए कौन सा शॉर्टकट है?
Ctrl + ]
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में पैराग्राफ को बाईं ओर से इंडेंट (Indent) करने के लिए क्या शॉर्टकट है?
Ctrl + M
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में पैराग्राफ का बायां इंडेंट हटाने के लिए कौन सा शॉर्टकट है?
Ctrl + Shift + M
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में हैंगिंग इंडेंट (Hanging Indent) बनाने के लिए किस शॉर्टकट का उपयोग होता है?
Ctrl + T
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में हैंगिंग इंडेंट को समाप्त करने के लिए क्या शॉर्टकट है?
Ctrl + Shift + T
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में पैराग्राफ की सभी अतिरिक्त फ़ॉर्मेटिंग हटाने के लिए कौन सा शॉर्टकट है?
Ctrl + Q
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में कैरेक्टर फ़ॉर्मेटिंग (जैसे बोल्ड, इटैलिक आदि) हटाने के लिए क्या शॉर्टकट है?
Ctrl + Spacebar
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड में हाइपरलिंक सम्मिलित करने के लिए कौन सा शॉर्टकट उपयोग होता है?
Ctrl + K
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट वर्ड या अन्य ऑफिस ऐप्स में अंतिम बार किए गए कार्य को दोहराने (Repeat) के लिए कौन सी कुंजी है?
F4

माइक्रोसॉफ्ट वर्ड में अक्षरों का केस (Uppercase, Lowercase, Title Case) बदलने के लिए क्या शॉर्टकट है?
Shift + F3

माइक्रोसॉफ्ट वर्ड में स्पेलिंग और ग्रामर की जाँच करने के लिए कौन सी फंक्शन कुंजी है?
F7

माइक्रोसॉफ्ट वर्ड में शब्दों के पर्यायवाची (Thesaurus) खोजने के लिए कौन सा शॉर्टकट है?
Shift + F7

Ctrl + F12

Ctrl + Shift + F12

माइक्रोसॉफ्ट एक्सेल में वर्तमान सेल से डेटा क्षेत्र के अंतिम किनारे तक जाने के लिए क्या उपयोग होता है?
Ctrl + Arrow Keys
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट एक्सेल में सेल का चयन एक सेल आगे बढ़ाने के लिए कौन सा शॉर्टकट है?
Shift + Arrow Keys
उत्तर देखने के लिए टैप करें
माइक्रोसॉफ्ट एक्सेल में डेटा वाले अंतिम सेल तक चयन का विस्तार करने के लिए क्या शॉर्टकट है?
Ctrl + Shift + Arrow Keys
उत्तर देखने के लिए टैप करें

Ctrl + Home

माइक्रोसॉफ्ट एक्सेल में वर्कशीट के अंतिम उपयोग किए गए सेल पर जाने के लिए कौन सा शॉर्टकट है?
Ctrl + End

Ctrl + Page Up

Ctrl + Shift + L
