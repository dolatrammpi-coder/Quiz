व्यंजन संधि (वर्ग का तीसरा)
उत्तर देखें
वर्ग के 1ले वर्ण (क्, च्, ट्, त्, प्) के बाद घोष वर्ण = 3रा वर्ण
उत्तर देखें
दिक् + गज = दिग्गज, वाक् + ईश = वागीश, सत् + धर्म = सद्धर्म
व्यंजन संधि (वर्ग का पाँचवाँ)
उत्तर देखें
वर्ग के 1ले वर्ण के बाद न् या म् = 5वाँ अनुनासिक वर्ण
उत्तर देखें
वाक् + मय = वाङ्मय, उत् + नति = उन्नति, जगत् + नाथ = जगन्नाथ
व्यंजन संधि ('त्' संबंधी नियम)
उत्तर देखें
त् के बाद च्/छ् = च्च, ज्/झ् = ज्ज, ट्/ठ् = ट्ट, ल् = ल्ल
उत्तर देखें
उत् + चारण = उच्चारण, सत् + जन = सज्जन, उत् + लास = उल्लास
व्यंजन संधि ('छ' संबंधी नियम)
उत्तर देखें
ह्रस्व स्वर के बाद 'छ' आने पर 'च्' का आगम
उत्तर देखें
परि + छेद = परिच्छेद, वि + छेद = विच्छेद, स्व + छंद = स्वच्छंद
विसर्ग संधि (ओ में परिवर्तन)
उत्तर देखें
विसर्ग से पहले 'अ' और बाद में अ या सघोष वर्ण = ओ
उत्तर देखें
मनः + अनुकूल = मनोनुकूल, यशः + दा = यशोदा, तपः + वन = तपोवन
विसर्ग संधि (र् में परिवर्तन)
उत्तर देखें

उत्तर देखें
निः + धन = निर्धन, दुः + बल = दुर्बल, निः + आशा = निराशा
विसर्ग संधि (श्, ष्, स् में)
उत्तर देखें
विसर्ग के बाद च्/छ् = श्; ट्/ठ् = ष्; त्/थ् = स्
उत्तर देखें
निः + चय = निश्चय, धनुः + टंकार = धनुष्टंकार, नमः + ते = नमस्ते
विसर्ग संधि (लोप नियम)
