Definitions, Concepts & Classification of Antonyms

Primary definition of an antonym
Word expressing an opposite meaning.
उत्तर देखने के लिए टैप करें
Etymological origin of the term antonym
Greek roots anti and onyma.
उत्तर देखने के लिए टैप करें
Three primary linguistic categories of antonyms
Gradable, complementary, and relational antonyms.
उत्तर देखने के लिए टैप करें
Definition of gradable antonyms
Opposites operating on a continuous spectrum.
उत्तर देखने के लिए टैप करें
Distinguishing characteristic of gradable antonyms
They permit intermediate degrees.
उत्तर देखने के लिए टैप करें
Classic example pair of gradable antonyms
Hot and cold.
उत्तर देखने के लिए टैप करें
Intermediate temperature states between hot and cold
Warm, tepid, and cool.
उत्तर देखने के लिए टैप करें
Definition of complementary (binary) antonyms
Mutually exclusive absolute opposites.
उत्तर देखने के लिए टैप करें
Core rule governing complementary antonyms
Denial of one asserts the other.
उत्तर देखने के लिए टैप करें
Classic example pair of complementary antonyms
Alive and dead.
उत्तर देखने के लिए टैप करें
Can complementary antonyms naturally accept gradable modifiers like 'very'?
No, they represent absolute states.
उत्तर देखने के लिए टैप करें
Definition of relational (converse) antonyms
Opposites describing reciprocal relationship or perspective.
उत्तर देखने के लिए टैप करें
Classic example of relational antonyms in trade
Buy and sell.
उत्तर देखने के लिए टैप करें
Example of relational antonyms in social hierarchy
Master and servant.
उत्तर देखने के लिए टैप करें
Example of relational antonyms in family kinship
Parent and child.
उत्तर देखने के लिए टैप करें
Definition of directional antonyms
Converse pairs denoting physical movement.
उत्तर देखने के लिए टैप करें
Example pair of directional antonyms
Ascend and descend.
उत्तर देखने के लिए टैप करें
Role of grammatical category in antonymy
Must match target word's category.
उत्तर देखने के लिए टैप करें
Antonym of an adjective must always be
An adjective.
उत्तर देखने के लिए टैप करें
Antonym of a noun must always be
A noun.
उत्तर देखने के लिए टैप करें
Antonym of a transitive verb must be
A verb.
उत्तर देखने के लिए टैप करें
Linguistic concept of polysemy affecting antonymy
Multiple word meanings have distinct opposites.
उत्तर देखने के लिए टैप करें
Why context determines precise antonym selection
Context activates the exact intended sense.
उत्तर देखने के लिए टैप करें
Definition of an auto-antonym (contranym)
A word with contradictory meanings.
उत्तर देखने के लिए टैप करें
Prominent example of an auto-antonym in English
Sanction (to permit or penalize).
उत्तर देखने के लिए टैप करें

Prefix-Based Antonyms & Morphological Rules

Definition of prefix-based antonyms
Opposites formed by adding negative prefixes.
उत्तर देखने के लिए टैप करें
Most common productive negative prefix in English
Un-
उत्तर देखने के लिए टैप करें
Antonym of 'certain' formed using prefix
Uncertain.
उत्तर देखने के लिए टैप करें
Etymological rule for using the prefix 'in-'
Commonly attaches to Latin-derived stems.
उत्तर देखने के लिए टैप करें
Antonym of 'capable' formed with negative prefix
Incapable.
उत्तर देखने के लिए टैप करें
Phonetic assimilation of 'in-' before letters p, m, b
Transforms into prefix 'im-'.
उत्तर देखने के लिए टैप करें
Antonym of 'mortal' using assimilated prefix
Immortal.
उत्तर देखने के लिए टैप करें
Antonym of 'pure' using assimilated prefix
Impure.
उत्तर देखने के लिए टैप करें
Phonetic assimilation of 'in-' before the letter l
Transforms into 'il-'.
उत्तर देखने के लिए टैप करें
Antonym of 'legitimate' using assimilated prefix
Illegitimate.
उत्तर देखने के लिए टैप करें
Phonetic assimilation of 'in-' before the letter r
Transforms into 'ir-'.
उत्तर देखने के लिए टैप करें
Antonym of 'rational' using assimilated prefix
Irrational.
उत्तर देखने के लिए टैप करें
Semantic function of the prefix 'dis-'
Denotes reversal, removal, or negation.
उत्तर देखने के लिए टैप करें
Antonym of 'harmony' using prefix
Disharmony.
उत्तर देखने के लिए टैप करें
Antonym of 'appear' formed with prefix
Disappear.
उत्तर देखने के लिए टैप करें
Semantic difference between 'uninterested' and 'disinterested'
Disinterested means impartial; uninterested means unconcerned.
उत्तर देखने के लिए टैप करें
Exact antonym of 'biased' or 'prejudiced'
Disinterested.
उत्तर देखने के लिए टैप करें
Function of prefix 'non-' in forming antonyms
Denotes objective absence or non-membership.
उत्तर देखने के लिए टैप करें
Antonym of 'conformist' using prefix
Non-conformist.
उत्तर देखने के लिए टैप करें
Semantic function of prefix 'mis-'
Signifies wrongly, badly, or incorrectly.
उत्तर देखने के लिए टैप करें
Antonym of 'understand' denoting wrong comprehension
Misunderstand.
उत्तर देखने के लिए टैप करें
Semantic function of prefix 'mal-'
Signifies bad, defective, or abnormal.
उत्तर देखने के लिए टैप करें
Antonym of 'benevolent' using Latin root replacement
Malevolent.
उत्तर देखने के लिए टैप करें
Semantic function of the prefix 'anti-'
Signifies opposed to or countering.
उत्तर देखने के लिए टैप करें
Semantic function of prefix 'counter-'
Signifies in response to or opposite.
उत्तर देखने के लिए टैप करें
