FINAL NOTES BUILDER

Architecture:
Main Subject Notes (8 subjects) -> unchanged.
Subject page -> optional Groups -> Chapters.
Chapter click -> Chapter Notes page.

Templates used:
templates/subject-page.html
templates/topic-notes.html

No chapter-page.html is used.

Groups are display-only organization. They are not inserted into URLs.

Generated Chapter Notes URL:
docs/subject-wise-notes/<subject>/<chapter>/index.html

Deleting a source JSON does not delete existing generated HTML.
